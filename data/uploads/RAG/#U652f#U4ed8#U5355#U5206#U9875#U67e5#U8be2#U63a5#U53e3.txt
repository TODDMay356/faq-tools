
# 1.支付单分页查询接口介绍
商城系统支付订单分页查询

# 2.基本信息
名称	内容
生产接口地址	https://payapi.inflyway.com/paycenter/api/order/payment/page/query
测试接口地址	https://test.inflyway.com/paycenter/api/order/payment/page/query
类型	JSON
METHOD	POST

# 3.参数
3.1 Header
参数名	是否必须	说明	示例
Content-Type	是	指定参数类型	application/json
Authorization	是	Basic xxxx	商户认证 merchant_id加secret_key，中间逗号:分割。经过base64编码，（商户号merchantId和商户秘钥secret_key请找技术支持提供）
user-agent	是	用户支付请求中请求头user-agent	必传
3.2 Body
字段名	数据类型	是否必传	说明
page_num	数字类型	是	页码
page_size	数字类型	是	页条数（最大50）
invoice_id	字符串	否	支付单业务单号
pay_order_id	字符串	否	支付单号
create_time_begin	字符串	否	开始时间，时间格式：2025-06-25 00:00:00
create_time_end	字符串	否	截止时间，时间格式：2025-06-25 00:00:00

# 4.响应
字段名	数据类型	是否必传	是否参与hash	说明
code	字符串	是	是	返回码 2000-成功，其他-失败
message	字符串	是	否	返回信息
page_num	数字	是	是	页码
page_size	数字	是	是	页大小
total_count	数字	是	是	总条数
merchant_id	字符串	是	是	商户ID
hash	字符串	是	否	验签hash
data	数组	是	否	数据
data.merchant_id	字符串	是	否	商户ID
data.merchant_name	字符串	是	否	商户名称
data.pay_order_id	字符串	是	否	支付单ID
data.order_no	字符串	是	否	业务单号
data.invoice_id	字符串	是	否	支付业务单号
data.create_time	字符串	是	否	创建时间
data.pay_amount	数字	是	否	支付金额
data.pay_currency	字符串	是	否	支付币种
data.fee_amount	数字	否	否	手续费金额
data.fee_currency	字符串	否	否	手续费币种
data.settle_amount	字符串	否	否	结算金额
data.settle_currency	字符串	否	否	结算币种
data.settle_status	字符串	否	否	结算状态
data.settle_status_desc	字符串	是	否	结算状态描述
data.pay_status	字符串	是	否	支付单状态
data.pay_status_desc	字符串	是	否	支付单状态描述
data.pay_failure_msg	字符串	否	否	失败原因
data.pay_time	字符串	否	否	支付完成时间
data.arn	字符串	否	否	arn
data.pay_method	字符串	否	否	支付方法
data.is_3ds	字符串	否	否	是否3ds认证 0-无，1-有
