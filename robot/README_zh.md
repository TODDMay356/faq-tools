# 微信API支持机器人

本项目实现了一个微信机器人，旨在作为跨境支付API的技术支持代理。该机器人监控微信群组中的提及消息，提取查询，与内部API接口交互以获取相关信息，并自动在微信群组中回复。

## 1. 解决方案概述

该机器人利用 `wxpy` 库进行微信集成。其模块化架构包括微信监听器、消息解析器、API客户端、响应格式化器和微信发送器。这种设计确保了可扩展性、可维护性和清晰的职责分离。

## 2. 技术栈

*   **Python**: 3.9+
*   **微信集成**: `wxpy` (基于 `itchat`)
*   **HTTP请求**: `requests`
*   **配置管理**: `configparser` 或 `python-dotenv`
*   **日志记录**: Python内置的 `logging` 模块

## 3. 项目结构

```
robot/
├── config.py             # 配置加载
├── api_client.py         # 处理与内部支付API的通信
├── message_parser.py     # 解析微信消息以提取查询
├── response_formatter.py # 格式化API响应以适应微信
├── wechat_bot.py         # 主要机器人逻辑，微信监听和发送
├── main.py               # 应用程序的入口点
└── README.md             # 本文件
```

## 4. 设置和安装

### 4.1. 前提条件

*   Python 3.9+
*   一个可以通过扫描二维码登录的微信账户（个人账户）。

### 4.2. 创建虚拟环境 (推荐)

```bash
python -m venv venv
source venv/bin/activate  # 在Windows上: .\venv\Scripts\activate
```

### 4.3. 安装依赖

```bash
pip install -r requirements.txt
```

(注意: 您需要创建一个包含 `wxpy`, `requests`, `python-dotenv` 的 `requirements.txt` 文件)

### 4.4. 配置

在 `robot/` 目录下创建一个 `.env` 文件，内容如下：

```
BOT_NAME=YourBotName  # 替换为您的机器人实际微信名称
API_BASE_URL=http://localhost:8000/api/v1  # 替换为您的内部API基础URL
API_KEY=your_api_key  # 如果需要，替换为您的API密钥
```

## 5. 使用

### 5.1. 启动机器人

您应该从项目根目录（即包含 `robot` 文件夹的目录）启动机器人，以确保 Python 能够正确解析内部模块导入。

导航到项目根目录（例如 `faq-tools/`），然后运行：

```bash
python -m robot.main
```

首次运行时，终端会显示一个二维码。使用您的微信手机应用扫描它以登录机器人。

### 5.2. 与机器人交互

机器人运行并登录后：

1.  **加入微信群**: 确保机器人的微信账户是相关微信群的成员。
2.  **提及机器人**: 在机器人是成员的任何群组中，通过其微信名称提及机器人（例如，`@YourBotName`），然后是您的查询。

    示例:
    `@YourBotName 查询订单XYZ123的支付状态`

3.  **接收响应**: 机器人将处理您的查询，调用内部API，并在群组中回复相关信息。

## 6. 可扩展性

*   **添加新的API端点**: 修改 `api_client.py` 以包含调用不同API端点的新方法。
*   **增强消息解析**: 更新 `message_parser.py` 以支持更复杂的查询结构或命令识别。
*   **定制响应**: 调整 `response_formatter.py` 以根据各种场景定制机器人的回复。
*   **高级功能**: 实现持久会话、自然语言理解 (NLU) 集成或更复杂的错误处理等功能。

## 7. 故障排除

*   **二维码未显示**: 确保您的终端支持显示图像或检查日志以获取二维码的URL。
*   **机器人无响应**: 验证 `.env` 中的 `BOT_NAME` 是否正确，以及机器人是否正确登录。
*   **API错误**: 检查 `api_client.py` 和内部API日志是否存在问题。
*   **微信账户被封禁**: 频繁或自动化的交互可能导致微信账户被临时或永久封禁。请负责任地使用机器人。

## 8. 开发注意事项

*   `wxpy` 依赖于网页微信客户端，这有时可能存在限制或不稳定。如果 `wxpy` 不足，可以考虑使用 `itchat` 进行更精细的控制。
*   始终保持您的微信账户安全。请注意您通过机器人暴露的数据。
